> 上线前逐项核对，给出**可验证的结论**，不靠假设。诚实标注哪些已测、哪些只做到什么程度，不把"构建通过"冒充"功能/安全验证通过"。

> **依据（官方通用验收标准）**：
> - 《制作网页应用 · 预览与测试》：功能是否可用、交互是否完善（各个按钮是否都能正确触发）、AI 能力是否正常 — https://docs.coze.cn/guides/vibe_coding_web_app
> - 《Coze CLI：开发并上线 Web 应用 · 预览与部署》：预览验收（内容完整/交互正常/视觉/多端）与部署确认（页面、按钮跳转、核心功能与预览一致）— https://docs.coze.cn/coze-cli-develop-and-deploy-a-web-application
> - 《部署网页应用 · 准备工作》：试运行通过、环境变量/域名/数据库同步等生产配置 — https://docs.coze.cn/guides/deploy_vibe_web
>
> 本清单为"交付闸门总出口"：上线前把各专项（功能可用、交互、质量安全、上线配置）的核对结论汇总到文末「总体结论」。它与 `交付前自检.md`（每轮改动自检）互为补充：自检管开发过程，本清单管上线定版。

## 〇、功能可用性与交互完整性（官方验收核心，上线前必查）

- [ ] **每个用户可交互点都有真实动作或跳转**（按钮、链接、导航、搜索框、表单/发布提交），目标可达。逐一点击验证：没有"看似可点、点了无反应"的元素。
- [ ] **跳转地址正确、无死链**：每个站内 href 指向的路由真实存在，运行返回 200（含动态详情页依赖的真实数据）。
- [ ] **核心功能链路完整可操作**：浏览 → 搜索 → 详情 → 发布 → 审核/展示 逐一走通，数据增删改查真实执行成功（非 mock）。
- [ ] **每个表单/输入入口能提交并落库或触达预期结果**：如搜索命中跳转、发布成功落表并返回详情、登录成功跳转。
- [ ] **元素完整显示、布局合理、样式符合设计**；多设备/响应式无遮挡、溢出、错位（电脑 + 手机各打开看一遍）。
- [ ] AI 能力（若集成，如文本/图片生成）：模型输出符合预期、流式/结果正常、失败有降级而非报错。

## 一、功能与流程
- [ ] 所有核心链路真实走通（如：浏览 → 搜索 → 详情 → 发布 → 审核 → 展示）。
- [ ] 每个接口真实请求验证（非 mock）返回正确，未用空数组交付冒充。
- [ ] 边界情况：空数据、超长文本、特殊字符、重复提交、并发提交、弱网/断网。

## 二、权限与安全
- [ ] 数据权限（RLS 或等效机制）真实生效：匿名/未授权用户只能读该读的，**写操作被堵死**。
- [ ] 不能绕过登录直接写数据（该项目有登录需求时说）。
- [ ] 注入、XSS、SQL 注入防护已在关键输入点生效。
- [ ] 越权访问他人数据被拦截（改 id 看别人私密字段等）。
- [ ] 敏感配置（密钥、Service Role）只存在于服务端/环境变量，未暴露前端/进 git。

## 三、数据一致性
- [ ] 核心业务规则真实按规则执行且可验证：
  - （信息平台示例）排序硬规则、90 天自动降权、隐私字段过滤、联系方式仅登录+满18可见。
  - （电商示例）支付/退款判定、库存/金额一致性。
- [ ] 规则验证已自动化或有明确的探测方法，不是"人肉看代码推断"。

## 四、性能与稳定性
- [ ] 数据量增大时关键查询有索引、响应正常。
- [ ] 依赖（数据库/第三方）断连时优雅降级，而非报错白屏/崩溃。
- [ ] 并发压力下不崩溃（视规模做压力测试）。

## 五、对抗测试三层
- **普通滥用**：
  - [ ] 匿名绕过发布/写操作被拦截。
  - [ ] 刷单 / 重复发布 / 超长输入不能撑爆页面或污染数据。
- **漏洞挖掘**：
  - [ ] 越权读取他人私密信息被拦截。
  - [ ] XSS 注入不能执行。
  - [ ] 篡改他人发布内容被拦截。
- **压力异常**：
  - [ ] 大并发下系统不崩溃。
  - [ ] DB 断连时降级而非白屏。

## 六、运营与合规
- [ ] 数据备份可恢复（导出/快照/恢复演练）已确认。
- [ ] 发布内容审核闭环（举报 + 管理员下架）存在。
- [ ] 写操作留日志 + 时间戳，可追溯。
- [ ] 基础运营数据埋点存在（访问量/热度）。
- [ ] 隐私合规已核对（当地法律；社交/证件/金融/未成年等敏感数据）。
- [ ] 外部依赖（DB/登录/存储/域名/SSL）在外部配置处已就位。

## 七、质量评估汇总
- [ ] 静态质量：类型检查 / lint / 构建通过（含云端 CI 复测，若已绑定 GitHub）。
- [ ] 自动化回归：核心纯逻辑单测存在且通过（排序硬规则、隐私红线、发布字段校验等）。
- [ ] 验收工具：web 项目用官方 `test_run`（静态 + 页面探活 + 接口冒烟）；最后一处代码修改后必有一次成功的验收。
- [ ] 上线配置核对：生产环境变量齐全（不硬编码）、域名/可见性/数据库同步/回滚就绪。
