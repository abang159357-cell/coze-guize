## 〇、功能可用性与交互完整性（官方验收核心，上线前必查）

1. **每个用户可交互点必须有真实动作或跳转**（按钮、链接、导航、搜索框、表单/发布提交），目标可到达；**逐个点击验证**，不得存在"看似可点、点了无反应"的元素。发现死点即判定未达标，不得上线。
2. **跳转地址必须正确、无死链**：每个站内 href 指向的路由真实存在，运行时返回 200（动态详情页须依赖真实数据验证，不得用空数据冒充命中）。存在死链是硬伤，须修复后重新验证。
3. **核心功能链路必须完整可操作**：浏览 → 搜索 → 详情 → 发布 → 审核/展示逐一走通，数据增删改查真实执行成功（非 mock）。任一步骤走不通即未达到上线条件。
4. **每个表单/输入入口必须能提交并落库或触达预期结果**：如搜索命中跳转、发布成功落表并返回详情、登录成功跳转。提交失败或未落库即判定该项不达标。
5. **元素必须完整显示、布局合理、样式符合设计**；多设备/响应式无遮挡、溢出、错位（电脑 + 手机各打开验证一遍）。不符设计基线即判定上线受阻、须调整。
6. **集成 AI 能力时（若有，如文本/图片生成）：模型输出必须符合预期、流式/结果正常、失败有降级而非报错**。未验证或降级缺失即不得上线该能力。

## 一、功能与流程

7. **所有核心链路必须真实走通**（如：浏览 → 搜索 → 详情 → 发布 → 审核 → 展示），以真实请求/真实打开页面验证，不得用空数组交付冒充命中。
8. **每个接口必须真实请求验证（非 mock）返回正确**；以空数组/占位数据冒充验证结果视为未验证。
9. **必须覆盖边界情况**：空数据、超长文本、特殊字符、重复提交、并发提交、弱网/断网；任一未覆盖且无理由，即该项不达标。

## 二、权限与安全

10. **数据权限（RLS 或等效机制）必须真实生效**：匿名/未授权用户只能读该读的，**写操作必须被堵死**（实测提交流程验证，而非代码推断）。
11. **不得绕过登录直接写数据**（项目有登录需求时）。
12. **注入、XSS、SQL 注入防护必须在关键输入点生效**（实测注入载荷验证）。
13. **越权访问他人数据必须被拦截**（改 id 看别人私密字段实测验证）。
14. **敏感配置（密钥、Service Role）只存在于服务端/环境变量，不得暴露前端/进 git**（扫描确认）。

## 三、数据一致性（按业务触发：有核心业务规则/排序/权限过滤的项目必做）

15. **核心业务规则必须真实按规则执行且可验证**：排序硬规则、90 天自动降权、权限过滤、联系方式仅登录+可见等（或电商的支付/退款、库存/金额一致性）；缺验证方法即不达标。
16. **规则验证必须已自动化或有明确的探测方法**，不得"人肉看代码推断"冒充验证。

## 四、性能与稳定性

17. **数据量增大时关键查询必须有索引、响应正常**；无索引或响应退化即该项不达标。
18. **依赖（数据库/第三方）断连时必须优雅降级**，不得报错白屏/崩溃。
19. **并发压力下不得崩溃**（视规模做压力测试；超规模未测须如实标注）。

## 五、对抗测试三层（按业务触发：有用户输入/写接口/多人内容的项目必做）

- **普通滥用**：
  20. 匿名绕过发布/写操作**必须被拦截**。
  21. 刷单 / 重复发布 / 超长输入**不得**撑爆页面或污染数据。
- **漏洞挖掘**：
  22. 越权读取他人私密信息**必须被拦截**。
  23. XSS 注入**不得**执行。
  24. 篡改他人发布内容**必须被拦截**。
- **压力异常**：
  25. 大并发下系统**不得**崩溃。
  26. DB 断连时**必须**降级而非白屏。

## 六、运营与合规（按业务触发：有用户内容/个人数据/写操作的项目必做）

27. **数据备份可恢复必须已确认**（导出/快照/恢复演练）；未演练即视为未验证。
28. **发布内容审核闭环（举报 + 管理员下架）必须存在**；无即判定运营底线缺失。
29. **写操作必须留日志 + 时间戳，可追溯**。
30. **基础运营数据埋点必须存在**（访问量/热度）。
31. **隐私合规必须已核对**（当地法律；社交/证件/金融/未成年等敏感数据）。
32. **外部依赖（DB/登录/存储/域名/SSL）必须在外部配置处已就位**；未就位不得上线。

## 七、质量评估汇总

33. **静态质量必须通过**：类型检查 / lint / 构建通过；绑定 GitHub 的项目以云端 CI 复测为准，未绑定则以本地官方验收工具为准。
34. **自动化回归必须存在且通过**：核心纯逻辑单测（排序硬规则、隐私红线、发布字段校验等）；无单测覆盖的核心逻辑即不达标。
35. **验收工具必须用官方工具**（web 用 `test_run`：静态 + 页面探活 + 接口冒烟）；**最后一处代码修改后必须有一次成功的验收**；不得用 shell 命令行自验证绕过。
36. **上线配置必须核对完毕**：生产环境变量齐全（不硬编码）、域名/可见性/数据库同步/回滚就绪。
